# 直播稿示例：AI 电台/知识分享型开场（演示标记语法）

大家好，欢迎来到我们的直播间。
今天想和大家聊一个话题：怎么用 AI 帮自己做一条短视频。

# 第一步：先想清楚要讲什么

很多人一上来就找工具，其实工具是最不重要的。
[[no interrupt]]先想清楚三件事：你讲给谁听、他为什么要听、听完他记住哪一句话。
这三件事没想清楚，后面全白搭。[[/no interrupt]]

想不清楚怎么办？写下来。
写在纸上，写在手机备忘录里都行。

# 第二步：写脚本

脚本不用长，一百五十字到三百字，正好是一条一分钟以内的短视频。
开头三秒一定要抛出问题，比如"为什么你的视频没人看"。
中间给方法，方法给两到三条就够了，贪多嚼不烂。
结尾一定要有行动指令，告诉大家看完这条视频应该去做什么。

[[待插:感谢刚才支持我的朋友，你们的支持是我持续更新的动力]]

# 第三步：拍和剪

用手机原相机拍就行，光线比设备重要，面朝窗户站。
剪映的自动字幕功能可以直接用，字幕一定要大，要居中。
